# Live Interpretation: iPhone smoke test

Use a physical iPhone and the same locale and audio route as your normal VTM setup. For LiveContainer, test using an existing JIT-less setup first. A successful Xcode build verifies compilation and packaging, not audio permissions, inference latency, or LiveContainer compatibility.

1. In **Settings → Model Management**, download a multilingual Whisper model for speech recognition. In **Offline Translation Language Packs**, confirm English is built in and download Chinese and Japanese in the foreground over Wi-Fi. These are ML Kit text-translation assets, not new Whisper models. Leave the language-pack page and return: verify each download shows its actual status and repeated taps do not start duplicate downloads. Restart the app after completion and check the packs still show as available.
2. Open **Live Interpretation**, choose Chinese ↔ English, and allow microphone access only after tapping Start. Check that language labels are readable at a large Dynamic Type size and the same language cannot be selected twice. Without touching the controls between utterances, say “你好，请问地铁站怎么走？”, pause, then “The subway entrance is across the street.” Pause and repeat with a third Chinese sentence. Verify each row shows the correct detected source and opposite translation. The app picks between the two selected languages for each voiced phrase, even when the scores are close. Speech in a third language or a phrase mixing both languages can therefore be routed inaccurately. Test short replies such as “好” and “对”; ordinary silence must not create a transcript.
3. Try the same sentence at your natural pace and faster, then a long statement with and without short pauses. Check for dropped or repeated words across boundaries, unwanted silent transcription, duplicate history, and UI responsiveness. Record time from the end of each phrase to the text and translation independently; the first phrase may take longer.
4. Stop explicitly, switch to a different tab, and repeat with the Home gesture and with an audio interruption. In all cases expect listening to stop and not restart automatically. Return to the original Translate tab and confirm push-to-talk still works.
5. Return to Live Interpretation and relaunch the app. Verify that finalized history persists locally, that Clear History requires an explicit confirmation, and that a language change affects only the new session.
6. While stopped, switch between Whisper Small, Small Q5, and Large v3 Turbo Q5. Confirm an absent model shows a download path rather than silently selecting a different model; after downloading, confirm each selected model starts. In an A/B comparison, hold input, language pair, and audio route constant. Record time to first text, translation completion, visible accuracy, and interruptions or thermal slowing. Separate model download and initial load time from steady-state measurements.
7. With airplane mode on, choose Chinese ↔ Japanese and verify both directions work using the same installed Whisper model and translation packs. Then choose a language whose pack was never downloaded. Start must show the missing pack and a route to Model Management without starting a download or requesting microphone access. Open Model Management from the hint, return, and confirm the chosen language pair is unchanged. Confirm a failed explicit download is not labeled installed and can be retried once Wi-Fi is available. Test the same missing-pack condition in the ordinary Translate tab.
8. On a physical device running iOS 26 or later, check that **Speech Recognition** and **Translation** selectors are distinct in the smaller live header. Change one and verify the other selection and the language pair remain unchanged. Check the compact layout with long language/model names and large Dynamic Type.
9. Select **Apple System Translation** without installing its language packs. Verify the app reports the selected pair as missing or unsupported, without starting the microphone, substituting ML Kit, or initiating a download. Use only the explicit language preparation action to approve the OS download. Recheck status after returning and after relaunch.
10. With Apple's packs installed, test Chinese ↔ Japanese in both directions and ordinary translation in airplane mode. Repeat in the same LiveContainer guest data container with JIT disabled. The Apple model path cannot be functionally verified in the iOS Simulator. Test an older iOS device if available: ML Kit remains usable, and Apple is unavailable without a crash or a changed deployment target.
